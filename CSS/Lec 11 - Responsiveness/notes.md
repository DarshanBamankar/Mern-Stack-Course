to make our website responsive we use the @media keyword ---->

ex - 
@media screen and (max-width : 600px){
    .className{
         css-propertites
    }
}

this implies that when the screen size becomes less than 600px, apply the css style provided below.(overriding the original one)

properties ->

1) max-width
2) min-width

Two approaches - 

1) Desktop first(shrink)
2) Mobile first(expand) -> used oftenly
